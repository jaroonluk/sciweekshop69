# หมายเหตุ:
# - ไฟล์ ~$แบบตอบรับ.xlsx เป็นไฟล์ล็อกชั่วคราวของ Excel (เกิดเมื่อเปิดไฟล์ค้าง)
#   ให้ปิด Excel ก่อนอัปโหลด และอัปเฉพาะไฟล์แบบตอบรับจริง
# - ไฟล์ข้อมูลร้านค้าปี 2569:
#     รอบที่ 1 = แบบตอบรับ.xlsx
#     รอบที่ 2 = แบบตอบรับ69_รอบ2.xlsx
#     รอบที่ 3 = แบบตอบรับ69_รอบ3.xlsx
#   สถานะคัดเลือกแยกไฟล์: data/status_store.json (รอบ 1), data/status_store_r2.json (รอบ 2), data/status_store_r3.json (รอบ 3)
# - ต้องอัปโหลดโฟลเดอร์ data/ ด้วย และตั้งสิทธิ์เขียนได้:
#     chmod 775 data   (หรือ 777 ถ้าระบบยังเขียนไม่ได้)
#   สถานะตรวจเอกสาร/คัดเลือกร้าน เก็บที่ data/status_store*.json เป็นหลัก
#   ข้อมูลผู้สมัครยังอ่านจากไฟล์ Excel ของรอบที่เลือกเสมอ (ไม่ถูกลบ)
# - Google Login: คัดลอก auth_secrets.example.php → data/auth_secrets.php
#   แล้วใส่ Client ID/Secret (อย่า commit ไฟล์นี้) · Redirect URI = .../auth_callback.php
# - Excel จะถูกซิงก์สถานะเมื่อเซิร์ฟเวอร์เขียนไฟล์ .xlsx ได้
#   ถ้าเขียน Excel ไม่ได้ ระบบยังบันทึกสถานะใน data/status_store.json ได้ปกติ
