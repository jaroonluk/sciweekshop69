# หมายเหตุ:
# - ไฟล์ ~$แบบตอบรับ.xlsx เป็นไฟล์ล็อกชั่วคราวของ Excel (เกิดเมื่อเปิดไฟล์ค้าง)
#   ให้ปิด Excel ก่อนอัปโหลด และอัปเฉพาะ แบบตอบรับ.xlsx
# - ต้องอัปโหลดโฟลเดอร์ data/ ด้วย และตั้งสิทธิ์เขียนได้:
#     chmod 775 data   (หรือ 777 ถ้าระบบยังเขียนไม่ได้)
#   สถานะตรวจเอกสาร/คัดเลือกร้าน เก็บที่ data/status_store.json เป็นหลัก
#   ข้อมูลผู้สมัครยังอ่านจาก แบบตอบรับ.xlsx เสมอ (ไม่ถูกลบ)
# - Excel จะถูกซิงก์สถานะเมื่อเซิร์ฟเวอร์เขียนไฟล์ .xlsx ได้
#   ถ้าเขียน Excel ไม่ได้ ระบบยังบันทึกสถานะใน data/status_store.json ได้ปกติ
